MODERNISATION NOTICE

About this site
This site is a modernisation of the BT Technology Journal Millennium Edition, which was released in January 2000 and contains various videos and interactive elements in addition to the text of the papers.

Modern browsers will support this site natively without the need for any additional software. Please ensure JavaScript is enabled to use the interactive elements.

Known issues
These are a bit beyond my skills to fix, if you'd like to help with these or any other issues you find then PRs are more than welcome on the GitHub repository :-)

  • DHTML is not working under "Process Engineering for the Alliance Partners"
  • Some Shockwave interactive elements do not work and may cause browser tab hangs
  • Poor accessibility due to original design of site

Changes from original

  • Deep links implemented to make it easy to link to specific pages
  • Videos have been converted to MP4 (except those used to demonstrate video compression)
  • Adobe/Macromedia Flash interactive elements are emulated using Ruffle
  • Adobe/Macromedia Shockwave (Director) interactive elements are emulated using dirplayer-rs
  • Java applets are emulated using CheerpJ

Where to find the original

  • ISO image of journal CD on the Internet Archive
  • original-files branch on GitHub
  • PDFs of the journal articles are available online at the BT Archives
