Nature-inspired Computation:Towards Novel and Radical Computing

Information Chemistry

Having outlined some examples of nature-inspired computation with immediate applications, we turn now to the more ambitious and long-term research. Information chemistry is a new computing paradigm inspired by the metabolism of living cells.

In very crude terms, the field of nature-inspired computation can be divided into 'stealing methods from nature' and 'stealing principles from nature'. Of course, it's usually the case that any example will contain some method and some principle. For example, the fruitfly solution to the channel allocation problem is largely a stolen method: the feedback loop established between a base station and its neighbour is copied from the loop established between neighbouring cells. However there is also an element of principle: the cellular analogy itself, whereby all decision-making occurs locally, is more profound than the actual details of that decision-making process in any particular instance. The information chemistry architecture, which is the fourth and final example of nature-inspired computation, is predominantly a theft of principle. It is inspired by the way in which a living cell carries out its processing tasks, but not by the exact details of any one of those tasks. Because of this it is also the example which has the most potential to significantly improve computing for a general domain of problems but, currently, it has the least tangible application to a specific problem.

Cellular and Molecular Paradigms

In recent years computational models of cells and cellular systems have been attracting increasing attention [23, 24]. There have also been interesting developments in the field of molecular computing [25, 26], and Adleman [27, 28] and Lipton [29] have shown how the massive parallelism of molecular systems can be exploited to solve combinatorial computations using techniques drawn from molecular biology. Some of this work has been in the domain of biologically inspired computation, while the latter work used real chemicals and laboratory techniques.

Figure 7 shows a simulation system which we have developed [30] to explore a novel alternative to the Von Neumann model. The architecture is inspired by analogy with a simple biological cell, which contains both enzymes and molecular substrates. The enzymes' role is to selectively enhance the required chemical reactions while inhibiting others; they can thus be thought of as molecular 'processing elements' which transform molecules. By drawing an analogy between the molecular substrates (on which the enzymes act) and data items, we can use a similar model to process information data items rather than molecules. In figure 7 the data items consist of terminated strings of numbered elements (red) and the processing elements (enzymes) are illustrated by the larger circles (green, mauve). This particular system is 'programmed' to carry out a simple information processing task - namely to sort numbers.
 

Fig7. A simulated 'information chemistry' performing a number-sorting task.

Simple, Parallel, Local Actions = Global Sorting

The processing carried out is a result of the emergent interactions of the data items (moving randomly through the system) with the enzyme processing elements. There is no central co-ordination or clocking of the system. Nevertheless, the system succeeds at its number-sorting task by using two types of processing element shown in figure 8. The operation of each processing element, as for real enzymes, is governed by specificity and function. The former defines which class of data items is matched (bound) and the latter determines the data transformation carried out. The 'join' enzyme is responsible for concatenating lists and results in monotonically increasing lists, although often with large 'gaps'. The 'break' enzyme acts in the presence of single-valued lists to cause large strings not containing that value to be broken apart at some arbitrary position. The net result is that number sorting occurs.

 


Fig 8. (a) join and (b) break enzyme operations

The system is remarkably tolerant to the removal of occasional data items, and enzymes will simply ignore inappropriate (noisy) data as the binding criteria will not be met. The kinetics of the system can be smoothly varied as can the specificity (which is a pattern-matching process). This raises the possibility that such a system may prove to be suitable for automatic evolution to perform an information-processing task, as it meets at least some of the evolvability criteria described above.
