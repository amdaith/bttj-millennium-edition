The Broadband Access Facility

Pushing fibre closer and VDSL

Figure 5 is a simplified logical diagram of FTTCab in the Broadband Access Facility. The APON is terminated at the ONU; an ATM25 interface at the ONU enables connection to the VDSL system at the Cabinet [2]. A telephony facility on the final copper drop is provided through the use of POTS splitters and tie cables to the telephony PCP (Primary Cross connect Point). The current prototype VDSL system provides 25 Mbits/s downstream, and 12 Mbit/s upstream over 1 km of 0.5 mm copper twisted pair in what is ostensibly a noise-free environment. Achievable bit rates will decrease when the system is introduced into the network due to increased crosstalk and impulse noise. It is still a valuable exercise to test a range of systems within the facility at these higher rates, in order to cover future contingencies and possible bandwidths.

At the customer end a POTS splitter provides connections for a standard POTS NTE (Network Termination Equipment) and the VDSL NTE. The VDSL NTE presents an ATM25 interface to the customer.

Fig 5. FTTCab logical network implementation in the FSAN Demonstrator

To demonstrate the multi-service capability offered by VDSL an ATM work-group switch was installed at the customer end of the network. This allows multiple client and applications to share the access pipe. Figure 5 shows a typical configuration, in which two PCs are connected to the switch via ATM25. Typically, one of the client PCs runs a web-browser demonstrating ultra-fast Internet access via a gateway from the Broadband Access Facility core network or an NT server connected indirectly to the core ATM switch. IP over ATM is provided across either ATM PVC (Permanent Virtual Circuit) connections or ATMF (ATM Forum) LANE (LAN Emulation) SVCs (Switched Virtual Circuits). The LES (LAN Emulation Server) and BUS (Broadcast Unknown Server) reside higher in the network. An IP TV server streaming video at up to 2 Mbit/s connected to the FSAN Demonstrator core network allows video to be displayed on a second client PC. The network configuration also supports broadcast TV quality video using DMV MPEG decoders connected to the customer end ATM switch via an ATM25 interface. Connection to the ATM Warren HAN (Home Area Network) is also supported. [4]
