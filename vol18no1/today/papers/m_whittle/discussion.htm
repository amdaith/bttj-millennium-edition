The Broadband Access Facility

Discussion of issues from implementation of example services

The implementation of FTTCab, as described in Section 4, required the provision of a CBR circuit across the core and access portion of the network, in order to support the transport of MPEG encoded video streams. The network topology involved setting up a permanent virtual circuit across two ATM switches in the core network, provisioning an appropriate channel across the PON in the optical access section and setting up a CBR circuit in the customer premises ATM switch. This was a cumbersome and time-consuming process and would involve many operational difficulties if such a problem were encountered with a large number of customers. Investigations are underway in the Broadband Access Facility with respect to the provision of an effective Operational Support system which would enable the configuration of such services 'on the fly'.

The traffic produced by K-Net Cellstack MJPEG low latency codecs, as used in the high quality videoconferencing (figure 7), is VBR (Variable Bit Rate). Significant cell loss was observed when transporting traffic across the PON (622 Mbit/s downstream) & VDSL (25 Mbit/s downstream) access portion to the NTE. The average data rate of the MJPEG video + audio stream was 12 Mbit/s. Cell loss was eliminated through modifications to increase the FIFO (First In First Out) buffer size on the BT developed ATM25 Line Interface Module (LIM) at the ONU and the implementation of a traffic shaping function on the VBR traffic produced by the video codecs. Software upgrades to the Cellstack codecs will further control their traffic parameters. The ATM25 line interface at the ONU is an obvious potential network bottle neck. With current software versions it is also possible to use the element management system to provision more traffic than the ATM25 interface (or the VDSL system it is connected to) can cope with (overbooking). When provisioning PVCs across the same ATM25 interface on the PON, it is possible to adversely affect the quality of service for other users on that access. A more developed element manager should alert the operator of such occurrences to enable overbooking to be properly managed.

The two examples of a lack of traffic provisioning management which adversely affect the quality of service have highlighted the need for a test tool to determine the exact location of cell loss in complex heterogeneous networks. A project is currently underway at Adastral Park to provide an embedded ATM test tool, more appropriate to the needs of the Broadband Access Facility.

Using ATM Forum LANE, has also highlighted the issue of connection set up times. Breaks in service on the access portion of the network have a severe affect on an SVC protocol such as LANE. Any connections across the network must be reestablished once service is resumed resulting in the potential for many signaling requests to the LANE server. Experiments with short breaks in service such as those seen on metallic access networks have shown that PVC based applications are restored almost immediately. Thus the performance of the ATM signaling system is critical on DSL based access networks. Further work on the end to end performance of networks with DSL access portions is in progress at Adastral Park.
