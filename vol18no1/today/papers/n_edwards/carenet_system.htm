Lifestyle Monitoring for Supported Independence

The CAREnet Trial System

In order to be able to run a trial of CAREnet with real users (necessary to be able to truly evaluate CAREnet) a complete system to control and maintain the service had to be created. This system, as illustrated in figure 10, was relatively complex compared to the simple CAREnet proposition.

Fig 10. A Schematic Representation of the CAREnet Trial System

The elements within the system are described in table 1.

Sensors The sensors were designed to record environmental changes: in particular, to record which room a client was in and how active they were within that room. Room temperature and fridge usage were also recorded.
Control unit The control unit in the home recorded the data from the sensors and contained a communications device which allowed the data to be sent as required over the telephone network.
Telephone Clients and carers received messages from the IVR platform on a standard telephone, and could use their telephone to dial in to an automated service which allowed them to switch the system on and off.
Retrieval The data retrieval system contacted each home on a regular basis and retrieved the data.
Validation The validation checked the syntax of the data before it was processed.
Database The database stored the data in a form which represented a longitudinal lifestyle pattern and could be readily accessed.
Analysis The analysis system automatically looked through the data for possible problems.
Messaging The messaging system scheduled messages to clients and carers and received input from the IVR platform.
IVR The Interactive Voice Response (IVR) platform sent telephone messages as requested by the messaging system and received dial-in calls from clients and carers.
Viewer The viewer allowed the recorded data to be displayed graphically.
Plan generator The plan generator allowed information concerning the participation of a client or carer to be created directly from the database.
Fax reporting The fax reporting system generated a fax containing the details of each alert, and sent the fax to Anchor Trust.
System Monitor The system monitor regularly checked the status of all the components of the lifestyle monitoring system central hub and reported problems.

SMS and e-mail

SMS and e-mail messaging were used to inform the trial team of the status of the system.

Table 1. Components of the CAREnet Trial System

The development of this system led to the ability to conduct a comprehensive trial of CAREnet.
