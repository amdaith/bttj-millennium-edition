Mobile Software Agents for Control in Telecommunications Networks

Abstract

Distributed control can, in principle, have advantages in terms of speed of response and robustness over centralised control. However, the benefits of robustness are not realised automatically and, due to its more complex dynamics, distributed control can be just as brittle as centralised control. Distribution of control can also result in sub-optimal performance since global information is not normally available to each controlling process.

Mobile agents are computational processes which are capable of moving from node to node around a network. Their use is proposed for the control of distributed systems and, in particular, telecommunications networks. It is argued that the use of mobile agents can result in an intrinsically robust and adaptable control system when used in conjunction with suitable programming guidelines.

Mobile agents form a dynamic compromise between fully centralised and fully distributed control such that the balance between speed of response and optimality of response can be altered according to the conditions present in the system being controlled. This balance is adjusted by altering the number of agents present in the network, and by altering the number of nodes visited by an agent for information gathering before executing a control action.

Mobile agents are also a natural extension of object oriented programming to distributed systems. They allow a different method of partitioning program code which may be more intuitive than when restricted to static processes. Conceptually at least, there is always one process in charge of implementing a particular control algorithm. This contrasts with purely distributed control where, apart from algorithms specifically designed for distribution, the programmer will have to make a greater intellectual effort to map a control algorithm onto a number of distributed static processes.
