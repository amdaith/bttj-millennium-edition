Mobile Software Agents for Control in Telecommunications Networks

Testing the System

The Network

To test the agents' ability to spread traffic evenly in a network we needed a network with a number of alternative routes from node to node. This network must not be fully interconnected as there would always be a direct link to all other nodes and the network would be limited only by the capacity of its links. Also the network cannot be a tree network as there is will be no routeing decisions for the agents to make as there is only ever one route from node to node. We chose to use a proposed UK network as our test network, see figure 3. This network is sufficiently interconnected to give the agents routeing decisions to make and it also has the benefit of being a realistic network topology.

A network description file was created to set the positions of the 30 nodes in the network and the links connecting them. Links are defined as unidirectional and so nodes were connected with a link in each direction to represent a circuit. In this example all nodes in the network were given the same capacity.

 


Fig 3. The network used to test the agents

The Traffic Profile

Traffic in the network was represented by blocks of calls that were 2.5% of each nodes total capacity. The source and destination nodes were chosen so that there was a range of call distances, where the distance is the number of nodes a call travels through. As the initialised routes for the network were known it was possible to deliberately overload particular nodes by organising many calls to cross at one node. This was done for three nodes in the network.

The call blocks were scheduled to start at regular staggered intervals and the durations were arranged so that they all finished approximately together. The traffic generator module is able to apply a traffic profile to the network at any specified rate.

Measuring Agent Performance

The simplest experiment to evaluate the performance of a group of agents in a network is to compare the result of the same traffic profile with and without agents. This will show the advantage of the agents over a network with a fixed routeing table network.

The network was initialised with default routes (figure 4). When the traffic profile was applied to the network three nodes overloaded, as expected. The peak traffic level in the network reached 115%. The traffic profile applied to the example network is shown in figure 5 . Note that nine nodes are completely unused.

To test the system with agents present, the routes were initialised as before, and a parent monitor was started on a node. The parent monitor then launched the required number of parent agents. For a network of this size, two parent agents are sufficient and this value had been pre-set. The traffic generator was then started with the same traffic profile as before. As there is a random element in the behaviour of the system the agents were tested with the traffic profile a number of times. Figure 5 shows the agents actively managing the traffic. The highlighted links show one the routeing table for one node.

Fig 4. Network traffic distribution without mobile agents

 

Fig 5. Network traffic distribution with mobile agents

As soon as the parent agents find traffic in the network, they calculate where load agents would be needed. As the amount of traffic in the network increases, so does the number of load agents. As traffic is added the maximum spare capacity routes could differ from the initial default routes. The load agents change routes in response to this and move call blocks away from congested nodes. In the tests the number of load agents typically peaked at about seven. When the traffic stabilises and then is removed from the network, no more load agents were launched. Figure 5 shows a typical result, with the network at the point of peak traffic.

Comparing the results in figures 4 and 5 shows the benefit of the agents. The agent-managed network had a maximum node utilisation of 85%; no nodes are overloaded. This was achieved as the agents spread the traffic more evenly to use all the nodes; notice that there were no nodes that remained unused.
