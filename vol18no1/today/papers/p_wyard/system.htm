System Design

In order to achieve the functionality and style of interaction described above, we developed a system architecture as shown in the figure 7.

Fig 7. System architecture, click on this diagram to find links to each of the system components

The architecture is essentially that of a typical state-of-the-art advanced spoken language system, with additions for multimodality.

A very brief description of each component follows:

  • User interface - as in figure 7 . It comprises three parts - the virtual assistant, the 3D virtual world, and the fabric palette. It also contains the speech recogniser.
  • NLU (Natural Language Understanding) - converts speech recogniser text output into a meaning representation.
  • Touch interpreter - converts raw touches on palette or VW to 'touch semantics', i.e. a touch on a sofa or a touch on fabric #65, as opposed to a touch on pixel [327,126] .
  • Modality Unification - integrates speech and touch semantics.
  • DM (Dialogue Manager) - processes the input semantics in the current dialogue context. Co-ordinates other modules to generate the system response. Handles anaphora and ellipsis resolution. Controls system initiative generation.
  • Response generation - generates the text for the system output. This is sent to the talking head in the user interface.
  • Context help - provides help to the user, especially in the case of input which the system cannot process (error-recovery). This help is dependent on the type of error and the dialogue and world context.
  • System Initiatives - generates the system initiatives, which are triggered by dialogue/world state.
  • Fabric Matching - provides the intelligence to decide which fabrics match with which others.
  • Database Lookup - retrieves fabrics from the database according to the attributes specified.
  • Pricing - calculates the price of objects covered in fabrics, or the price of an entire selection in the virtual room.
  • Current world model - contains all needed information about the current state of the virtual world and the fabric palette.

The NL server is the combination of all modules apart from the user interface.
