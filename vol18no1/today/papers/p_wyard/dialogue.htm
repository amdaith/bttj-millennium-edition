Dialogue Manager

The Dialogue Manager is the central component of the NL server. It effectively controls and co-ordinates the external behaviour of the system, that is what the synthetic persona says, which fabrics are shown on the palette and in the Virtual World, the user's viewpoint and the position of the furniture.

The dialogue manager's primary role is to determine the user's intention, that is, given a set of semantic interpretations of speech and touch semantics from the modality integrator, determine which is the correct interpretation, and then act upon it. It utilises the current dialogue context to help determine ellipsis, anaphoric references, and continuity of dialogue. For example, if the system has just asked the user to indicate which object he or she would like to see a fabric on, and the user touches the sofa, then the modality integrator would return three possible combinations, indicating the sofa, the fabric on the sofa and its position. The dialogue manager determines that the correct interpretation is actually the object, sofa, since the dialogue context indicates that the user has been asked to indicate an object. Once the user's intention has been determined the system can respond appropriately. It utilises a complex behavioural model to determine the system's reaction to the user's intention.

The Dialogue Manager is designed so that reasonably complex, mixed-initiative dialogues can take place. A feature of the behavioural model is that it allows the system to adopt particular strategies when interacting with the user. For example, the system may adopt a salesperson strategy when selling fabrics where its aim may be to promote a particular brand, or sell, or it may offer the expertise of an interior designer suggesting advice on fabric combinations.
