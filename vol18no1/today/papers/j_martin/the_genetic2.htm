Using Genetics To Extract Information

The Genetic Algorithm

The genetic algorithm is based on a pool of randomly generated trees. During each generation, the main processes that take place are:

  • selection for the next generation

  • reproduction of the selected trees

Selection

There are currently four selection methods available:

  • Tournament - in tournament selection, a group of trees (group size is set by the user) is randomly selected and the tree with the best fitness is chosen from the group.

  • Greedy fitness Proportionate - this method is the same as fitness proportionate selection except that a fixed percentage, i.e. 40 %, of the time only the top x % is included in the selection.

  • Rank - rank selection redistributes the fitness of the trees over a user-defined gradient before using the fitness proportionate algorithm to select the trees. In this way closely grouped trees are spread along the fitness landscape allowing a better random choice.

Reproduction

After selection, one of the three operators, (copy, crossover or mutation) is applied with a fixed probability to each tree.

  • Copy - the tree is copied straight into the next generation without change. This allows good solutions to be kept.

  • Crossover - crossover involves two trees. A point is selected within both trees and the subtrees are swapped over at that point. The father tree (the one originally selected for the next generation) is then placed into the next generation while the mother tree is destroyed. This makes sure that the pool size stays constant over the generations. Crossovers resulting in too deep trees are not allowed.

  • Mutation - the subtree of a randomly picked point within the tree is destroyed and a new one is grown using the variable growth method. The maximum depth of the tree is limited as before.
