Towards Human-Centred Intelligent Systems: The Intelligent Assistant

Information management

The objective of the information management components of the IA is to assist the user to gather the required information. They provide a more natural way of specifying what is required and an enhanced search strategy that is tailored to the user's interests. There are two components in the IA for information management - The Yellow Pages Assistant and the Web Assistant.

Yellow Pages® is a printed classified directory that contains advertisements in various sizes and formats. A similar service called Talking Pages® is also offered over the telephone. There is some free-form text associated with each advertisement together with a keyword that identifies the classification to which it belongs. Links between classifications are also present. Talking Pages data contains a lot more free-form text and other information such as payment method and postcode. There are keywords for each advertisement but cross-classification links are absent.

Searching through the Yellow Pages and Talking Pages is done using the keywords associated with each advertisement. It is very important to have a set of 'good' keywords that can sufficiently describe the advertisements. In the case of the Talking Pages call centre, customer service agents (CSAs) perform the search on behalf of the customer. Their experience with the classifications is crucial to the success of a search and directly affects the length of an enquiry session.

The Yellow Pages Assistant (YPA) project [8] aims to provide an intelligent search engine for semi-structured data source such as the Yellow Pages and Talking Pages. It allows natural interaction with the user and without the need for detailed knowledge of the classifications.

A query can be entered either by typing or by a spoken sentence. It can be a complete sentence or a phrase stating the user's requirement. For example, 'guest house in Colchester' is equally as good as 'I want to repair my bicycle'. When a query is received, the YPA puts the words in the query into different categories. These categories correspond to the indices produced earlier. When one or more advertisements are found, they are ranked in relative relevancy and are presented to the user. If no advertisement can be found using the words in the original query, the YPA will try to expand the search scope by incorporating some common sense knowledge and synonyms. In situations where more information is needed from the user to expand or narrow the scope of search due to ambiguous terms in the query, the YPA will engage the user in a dialogue. In the IA, the YPA uses the user's location (e.g. Colchester) and user's preferences (e.g. Italian food) to expand general and specific queries. It is possible to test the general YPA prototype using guest as login identification and Willkommen as password (case sensitive).

The Web Assistant acts as the interface between the user and the World Wide Web. It performs appropriate keyword expansion, again based on the user's interests and some common sense knowledge. It employs a meta-search engine that consolidates all the results from many search engines. The biggest difference between the YPA and the WA is that there is no keyword index residing in the assistant itself. A detailed explanation on keyword expansion is available online.
