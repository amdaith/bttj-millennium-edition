The Multilingual World Wide Web

PenPal

PenPal is a translation system being developed at Adastral Park. PenPal differs from current commercial systems in that it uses the interlingual approach to translation and it is interactive; when the text to be translated is ambiguous, or cannot be analysed for any reason, PenPal will ask for clarification or re-wording in the author's language. In this way the quality of the translation produced by PenPal should be sufficient for users to author documents in languages that they do not speak. Current commercial systems can really only be used to translate into a language that the user speaks. This is because this is the only way that the user can be certain of the quality of the target text.

An example of using PenPal to produce an interlingual text, and then render this text in another language is shown in figure 4. The user enters a phrase, which PenPal analyses. PenPal realises that the phrase is ambiguous because several distinct interlingual structures are produced by the analysis. PenPal works backwards from the interlingua to determine which words are the source of the ambiguity. These words are then highlighted. When the user clicks on a highlighted word, a menu is presented which lists alternative meanings for the word. When the user has disambiguated all the highlighted words, the interlingua is produced.

Since the interlingua is unambiguous, no user interaction is necessary to produce the final text.

It may seem overly complicated to use an inference process to work back from the interlingua to determine which words are sources of ambiguity. However, the inferencing process allows PenPal to take into account any mutual constraints that there may be on the usage of words. For example, there may be grammatical or semantic constraints which mean that PenPal can reduce the number of options presented to the user.

There are several advantages to using the interlingual approach to machine translation. In terms of deployment as an application, we can store and transmit interlingual documents along with the original source text. This would make cross-linguistic document retrieval far more straightforward. In fact, since the interlingua is far less ambiguous than natural language, recall and precision would be significantly improved.

Another advantage is that it is easy to split the system into an interactive interlingua authoring tool and a fully automatic interlingua-to-target-text converter. This means that one could say, 'e-mail a single interlingual message to several people' and each could read it in their own language.

The core language processing components of PenPal can be used as the language-specific front-end processing for other natural language systems. Since the interlingua indicates the meaning of a text, other applications, such as interactive dialogue systems, could be built that take the interlingua as their input. Not only would they benefit from the grammar and lexicon that has been developed, but, producing an application in another language would mainly involved substituting the PenPal module for that language.

The way that PenPal carries out a semantic analysis of an input text gives it considerable flexibility over the depth of analysis used. In the initial stages of development of the system, translation may be fairly literal, but as more knowledge is added, PenPal's paraphrasing ability will improve and so the target text will improve in quality.

PenPal is partly an experiment in producing a wide-coverage natural-language processing system ('large' meaning a general-purpose grammar and a vocabulary of at least tens of thousands of words). As well as technical problems which are never addressed on small 'demo' systems, there are problems relating to the fact that several people will be responsible for developing the system, few of whom will have a knowledge of computational linguistics.
