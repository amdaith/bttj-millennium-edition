The Multilingual World Wide Web

Cross-linguistic Information retrieval

Information retrieval systems allow a user to find documents of interest from within a larger collection. In cross-linguistic information retrieval, the query and the documents may be in different languages.

Many systems now contain embedded information retrieval facilities. When internationalising an application, it may be desirable to support cross-linguistic information retrieval rather than simply port a monolingual information retrieval system.

Typically, information retrieval systems are based on keyword searching techniques. There are various techniques for improving simple keyword matching. To improve precision, attempts can be made to disambiguate keywords. Also, searching for groups of keywords which have to be within a certain distance of one another can improve precision. To improve recall, keyword expansion techniques, perhaps based on a thesaurus or ontology, can be used to augment the keyword list provided by the user. More sophisticated techniques include topic 'chaining' in which an ontology may be used to relate the words in the target texts in order to give some clues as to the discourse structure.

We may wish to port an information retrieval system to another language, in which case it will remain a monolingual system. Of more use would be to design the system in such a way that it is multilingual and can retrieve documents written in a range of languages, given a query in a single language [10].

Since keywords are at the centre of information retrieval techniques and keywords are of course language-dependent, making an information retrieval system multilingual means altering the way that information retrieval takes place.

When the database to be searched contains documents in a variety of languages, it is essential to be able to determine in which language each document is written In some cases, this may be contained in the meta-data for the document, in other cases it will have to be inferred from the content. The problems of determining the language of a document is now generally thought to be solved. Statistical and rule-based techniques can identify the language of a document with high accuracy typically within a couple of sentences. These systems can be confused however, by documents that contain text in more than one language.

The simplest approach to making an information retrieval system multilingual would be to use a set of bi-lingual dictionaries to translate the keywords into several languages and then search using the set of keywords appropriate for each document to determine its relevance. This method will have the effect of reducing the precision dramatically and also reducing the recall. Each possible sense of the original keywords will be expanded into several target language keywords which will reduce precision. Recall suffers because keywords often have a particular meaning in a given context. These meanings are often not included in bi-lingual dictionaries and so the intended sense may not be represented in the target keyword list.

To produce a multilingual information retrieval system with acceptable recall and precision, it will be necessary to use disambiguation techniques on the source keywords and on the target text as well as using a comprehensive dictionary for keyword translation.
