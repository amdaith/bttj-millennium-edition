Future Work

Work currently starting and planned for FreeUnet includes the following.

NAT-PT

At the moment our IPv6 experiments are based on dual-stack IPv4/IPv6 routers and hosts. Another class of experiments will use IPv6 only nodes in which case protocol translation is required for interoperability with IPv4 only systems. This mode of operation is likely to be used in smaller devices where storage space is at a premium and thus dual-stack is not an option. Network Address Translation-Protocol Translation (NAT-PT) [22] is a technology developed by the FreeUnet group for the IETF and allows IPv6-only networks to communicate with the IPv4 Internet. At the moment NAT-PT is at the final stages of specification in the IETF process. FreeUnet will incorporate IPv6-only subnets, interconnected natively with FreeUnet's IPv4/IPv6 FreeUnet and through NAT-PT to IPv4 networks.

Session Control

We are currently developing a series of tools relating to IETF session control and description protocols [23], primarily to assist in the establishment of multimedia sessions (unicast and multicast, with any number of participants). Currently we have implemented Session Invitation Protocol (SIP) clients, a SIP proxy server and a C library of SIP functionality. The SIP library will soon also support Session Description Protocol (SDP) [23] functionality. This work is developing towards session control for applications such as Voice over IP (VoIP), and using session control for temporary configuration of network state, e.g. temporary and per-session establishment of Quality of Service classes, per-session cost and policy-based routeing (over faster/expensive or slower/cheaper routes).
