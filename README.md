# BT Technology Journal Millennium Edition
The `main` branch in this repository is a modernisation of the BT Technology Journal Millennium Edition, which was released in January 2000 and contains various videos and interactive elements in addition to the text of the papers. The modernised version is faithful to the original look and feel of the journal.

It is available to browse online at:
- https://millennium.k6.tel

For more information on the changes made, please see the link above or the "modernisation notice" section of `index.htm` in the root folder of the `main` branch of this repository.
